📊 Analytics Overview
Real-time IPL batsman efficiency metrics from 1,247 match files (2008–2025)

Statistical Inference in Cricket Analytics

This project analyses real ball-by-ball IPL data from Cricsheet (2008–2025) to evaluate how four different statistical sampling strategies influence the accuracy of machine learning models trained to predict Batting Efficiency Scores.

Three regression algorithms — Linear Regression, Random Forest, and XGBoost — are trained independently on each sampled subset and on the full population, yielding 3 distinct models that are evaluated on a common gold-standard held-out test set.

Beyond performance, every player's dot-ball count is linked to a reforestation initiative: the Green Dot Ball Sustainability Initiative, aligning this cricket analytics study with UN SDG 13 (Climate Action) and SDG 15 (Life on Land).

Efficiency Metric Formulation

  Batting Efficiency Score Formula

Score =
  0.40 × Norm(Runs)
+ 0.30 × Norm(Strike Rate)
+ 0.20 × Norm(Batting Avg)
+ 0.10 × Norm(Trees Planted)

Min-Max normalization applied per feature across the full population before computing the weighted score.

📁 About the Dataset
Data provenance, features, and cleaning methodology

This research project applies four statistical sampling techniques to real ball-by-ball IPL match data (2008–2025) sourced from Cricsheet, and evaluates how each sampling strategy affects machine learning model generalizability for batsman efficiency prediction.

The population dataset contains — unique batsman-team profiles (after filtering inactive players from — raw records extracted from 1,200+ IPL match files). Each profile includes career batting average, matches, innings, total runs, strike rate, dot balls, and trees planted.

🌳 Green Dot Ball Sustainability Initiative

Dot balls represent a bowler dominating a batsman. Under the Green Dot Initiative, each dot ball triggers the planting of 19 trees — turning cricket performance data into an environmental impact metric.

Trees Planted = Dot Balls × 19

⚡ Batting Efficiency Score Formula

A multi-objective optimization score balancing performance and sustainability:

Score = 0.4·Norm(Runs) + 0.3·Norm(SR) + 0.2·Norm(Avg) + 0.1·Norm(Trees)

🎯 Project Objectives & Workflow
6-stage analytical pipeline from raw data to sustainability reporting
1. Data Collection & Aggregation
Ball-by-ball IPL match data (2008–2025) from Cricsheet is parsed across 1,200+ match CSV files. Player-level stats — runs, balls faced, innings, dot balls, dismissals — are aggregated per player-team using aggregate_data.py.
2. Data Cleaning & Feature Engineering
Players with fewer than 15 balls faced are filtered out. Batting average is computed where missing. The Trees Planted metric (Dot Balls × 19) is engineered, and Batting Efficiency Score is computed via Min-Max normalized features, saved to dataset.csv.
3. Statistical Sampling (n=150)
Four independent subsets are extracted: Simple Random Sample (SRS), Systematic (every k-th index), Stratified (proportionate per IPL team), and Cluster Sample (entire team groups as units).
4. ML Model Training (3 Models)
Linear Regression, Random Forest, and XGBoost regressors are trained separately on each of the five datasets (Full Population + 4 samples), yielding 3 distinct model architectures saved as .joblib files.
5. Gold-Standard Evaluation
All 3 models are evaluated on the same 20% held-out test population. R², RMSE, and MAE are computed and exported to results.json and results_table.csv.
6. Final Verdict & SDG Reporting
The dashboard renders the best sampling method and ML algorithm. Environmental impact (SDG 13 & 15) is calculated and visualized through interactive charts and a leaderboard of players ranked by Efficiency Score.
